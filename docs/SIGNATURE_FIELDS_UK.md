# Поля та квадранти в сигнатурі

З інтерфейсу прибрано «Топ знаків». Сам синтетичний знак, стихії, хрести та
полярність залишаються. Додано три незалежні розподіли за положеннями в домах:

| Група | Доми |
| --- | --- |
| Нічні поля | 1, 2, 3, 4, 5, 6 |
| Денні поля | 7, 8, 9, 10, 11, 12 |
| Східні поля | 10, 11, 12, 1, 2, 3 |
| Західні поля | 4, 5, 6, 7, 8, 9 |
| I квадрант | 1, 2, 3 |
| II квадрант | 4, 5, 6 |
| III квадрант | 7, 8, 9 |
| IV квадрант | 10, 11, 12 |

## Ваги та формули

- Сонце та Місяць: по 2 бали.
- Меркурій, Венера, Марс: по 1,5 бала.
- Юпітер, Сатурн, Уран, Нептун, Плутон: по 1 балу.
- Північний та Південний вузли: по 0,5 бала.
- ASC, решта кутів, Ліліт та Хірон не враховуються в полях і квадрантах.

Бал групи = сума ваг точок, поле `house` яких належить цій групі.
Враховується положення точки, а не її управління домами. Ретроградність вагу
не змінює. ASC виключений незалежно від його дому й не входить ані в бали
груп, ані в загальну вагу для відсотків, ані в вагу точок без визначеного дому.
Повна сума за наявності всіх зважених точок із визначеними домами — 14,5 бала.

У кожному розподілі точка враховується один раз: ніч + день = схід + захід =
сума чотирьох квадрантів = загальна вага точок із визначеними домами.
Ширина смуги = 100 × бал групи / цю загальну вагу. Порядок груп фіксований,
нульові значення відображаються. Ваги планет і вузлів у браузері відповідають
`SYNTHETIC_POINT_WEIGHTS` ядра, але для цих трьох розподілів ASC виключений.
У синтетичному знаку, стихіях, хрестах та полярності внесок ASC (1,5 бала)
залишається без змін; загальна вага цих показників може бути 16 балів.

## Збережені карти та невідомий час

Дані обчислюються для відображення з уже наявних `angles` і `bodies`, тому
працюють і зі старими збереженими картами без міграції та перерахунку ефемерид.
Видимість точок на колесі не змінює бали. Використовується система домів
відкритої карти. Положення й формули астрологічного ядра не змінено.

Якщо доми відсутні, показується повідомлення про недоступність полів і квадрантів.
Точки без цілого номера дому 1–12 пропускаються, їхня вага показується окремо.
Відсутнім домам не присвоюються умовні положення або нульові «результати».

Регресійні тести: `apps/api/tests/signature-fields.test.ts`. Запуск тестів,
збірки та сервера не виконувався на прохання користувача.
