# Карти та релокація у робочій зоні

Карти використовують усю ширину своїх блоків без колишніх обмежень
520/780 px. Кнопка розгортання відкриває карту через Fullscreen API браузера;
повторне натискання або Escape повертає звичайний вигляд. Доступність цього
режиму залежить від браузера. Номери натальних домів не мають світлої обводки,
прогностичні пунктирні куспіди мають темніший колір.

Календар прогресій має компактні колонки символів без зменшення шрифту даних.
Довгі формули переносяться. У формулах куспіди позначені арабськими цифрами;
у парі аспекту залишаються римські. Транзитні аспекти показуються символами,
датою екзакту й натальним домом, без колонки сили та score.

## Редагування відкритої карти

Кнопка олівця біля «Робоча зона» відкриває форму даних. Правки зберігаються
в чернетці; поточний результат не скидається під час введення. «Застосувати»
запитує новий розрахунок і замінює карту лише після успіху. Помилка залишає
попередню карту доступною. Форму можна залишити відкритою для порівняння міст.

Зафіксований пояс — числовий UTC-зсув у годинах, визначений для дати й часу
народження. Зміна міста при увімкненій фіксації не змінює цей зсув. За незмінних
дати й часу це зберігає момент народження UTC, змінюючи географічні координати.
Якщо фіксацію вимкнути, використовується часовий пояс обраного міста;
тоді незмінний локальний час може відповідати іншому моменту UTC.

Після застосування попередні прогнози скидаються як неактуальні. Початкова
збережена карта не перезаписується: редагований варіант можна зберегти окремо.
Ідентифікатор старої карти прибирається з URL. Для наступного відкриття
робочої зони записується локальна чернетка, якщо браузер дозволяє localStorage.

Ці зміни не змінюють формул астрологічного ядра.

## Фільтри транзитів

У таблиці транзитів на дату й календарі точних транзитів окремо обираються
транзитна планета (джерело) та натальна планета (ціль). Обидва фільтри
можна застосовувати разом. «Без транзитного Місяця» приховує лише події,
де Місяць є джерелом; аспекти інших планет до натального Місяця залишаються.
Точки, зокрема вузли та Ліліт, також доступні у списках.

Календар можна впорядкувати за датою, транзитною або натальною планетою;
всередині групи зберігається хронологія. Для огляду року встановлюється
період транзитів 365 або 366 днів. Фільтри застосовуються до отриманого
результату без нового API-запиту й не змінюють збережений прогноз.

У нових розрахунках транзитів натальними цілями є лише планети й точки
`natal.bodies`, без ASC, DSC, MC, IC та інших куспідів. Це стосується
поточного зрізу, тижневого огляду та календаря екзактів. У таблицях старих
збережених транзитів такі цілі приховуються. Положення планет у домах
та самі натальні доми залишаються доступними; прогресії й соляр не змінені.
Тижневий огляд залишається короткою добіркою API, а не повним календарем.
