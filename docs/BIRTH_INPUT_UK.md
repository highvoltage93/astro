# Текстове введення дати й часу народження

Поля народження на дешборді, у редагуванні натальної карти, формі народження
та синастрії використовують `type="text"`, а не системні календарі/селектори
часу Safari або мобільних браузерів. На телефоні запитується цифрова клавіатура.

- Дата відображається як `ДД.ММ.РРРР`. Можна ввести `20.06.1997`,
  лише цифри `20061997` або вставити ISO-дату `1997-06-20`.
- Час відображається як `ГГ:ХХ:СС`. Можна ввести `12:00:18` або `120018`.
  Старий формат `12:00` та числовий `1200` означають `12:00:00`.
- Після виходу з коректно заповненого поля відновлюються роздільники.
  Секунди не округлюються та не обрізаються.
- Перевіряються кількість днів у місяці, високосні роки, години 00–23,
  хвилини та секунди 00–59. Некоректна дата не переноситься на інший місяць.

До API передаються ті самі формати, що й раніше: `YYYY-MM-DD` та `HH:mm:ss`.
Перетворення не використовує часовий пояс браузера або об'єкт `Date`.
Часовий пояс народження й астрологічні обчислення залишаються окремими.

Під час неповного/некоректного введення батьківська форма отримує порожнє
значення, а текст залишається в полі для редагування. Це запобігає розрахунку
за попереднім коректним значенням, яке вже стерли. Форми блокуються валідацією,
кнопка синастрії також недоступна, доки необхідні дата/час не заповнені.
Вихід з незміненого поля не надсилає зайвого оновлення форми.

Якщо час невідомий, його поле вимкнене. Порожній час у запиті замінюється
технічним `12:00:00` разом із `birthTimeKnown=false`, як очікує чинне ядро;
це не вважається відомим часом народження. Значення `birthTimeKnown` не змінюється
самим текстовим полем.

Календарі періодів прогнозу, пошуку подій та фільтрів архіву не змінені.
Міграція БД не потрібна. Тести парсингу та збереження секунд:
`apps/api/tests/birth-input.test.ts`; їх підхоплює наявний CI.
