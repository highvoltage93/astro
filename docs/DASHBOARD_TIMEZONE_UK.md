# Часовий пояс на дешборді

## Підказки місця

Пошук міст на дешборді запускається автоматично від двох символів після
350 мс паузи у введенні. Результати відкриваються під полем місця. Нове введення,
закриття списку або вибір міста скасовує попередній запит; застарілі відповіді
не можуть замінити актуальні підказки. Кнопка пошуку та Enter повторюють пошук.
Стрілка вниз із поля переводить фокус на перший варіант; стрілки переміщують
фокус між містами, Enter вибирає, Escape закриває список.

Вибір міста оновлює назву, країну, координати та автоматичну IANA-зону.
Фіксований зсув залишається незмінним. Введення назви без вибору варіанта
саме по собі не змінює координати.

Поле показує зсув від UTC у годинах. Підтримуються від'ємні та дробові значення,
крапка або кома: `3`, `-4`, `5,5`, `5.75`. Дозволений ручний діапазон від −12
до +14 годин із точністю до хвилини. Порожнє або некоректне поле не дозволяє
розрахунок, а не перетворюється на UTC мовчки.

## Автоматичний режим

Замок відкритий. Місце з пошуку задає IANA-зону (наприклад, Europe/Kyiv).
Luxon визначає зсув для дати та місцевого часу народження, враховуючи правила
цієї зони й літній час. При невідомому часі використовується 12:00:00,
так само, як у розрахунковому ядрі. До API передається IANA-зона, не зсув
на сьогодні. Поведінка для переходів літнього часу залишається такою, як у ядрі.

## Фіксований режим

Натискання замка фіксує показаний зсув. Ручне редагування годин також вмикає
фіксацію. Зміна міста, координат, дати чи часу після цього не змінює зсув.
Координати та назва нового місця передаються у розрахунок як завжди.

Формула: `UTC = місцевий час − зсув у годинах`. Наприклад, 14:30 при +5,5
дає 09:00 UTC. У базі зберігається фіксована зона `UTC+05:30`, яку ядро читає
через Luxon; літній час до неї додатково не застосовується.

Повторне натискання замка повертає автоматичну зону останнього вибраного місця.
Фіксація стосується поточної форми; вона не є глобальним налаштуванням акаунта.
У збереженій карті фіксована зона зберігається та відновлюється разом з картою.

## Сценарії перевірки

- В автоматичному режимі зміна дати між зимою й літом оновлює зсув відповідно до зони.
- Після фіксації +3 вибір іншого міста змінює координати, але зберігає +3.
- Розблокування відновлює автоматичний зсув для нового міста й дати.
- +5,5 та +5.75 зберігаються як UTC+05:30 та UTC+05:45.
- Після збереження й повторного відкриття карти її UTC-момент не змінюється.
- Некоректне або порожнє ручне значення блокує запит розрахунку.

Тести, збірка та сервер у межах цієї зміни не запускалися.
