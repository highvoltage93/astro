# Збереження орбісів карти

## Базові значення (13 жовтня 2026)

Сонце, Місяць, Меркурій, Венера, Марс, Юпітер, Уран і Нептун: 8,5°;
Сатурн: 9°; Плутон: 6,5°; обидва вузли та Ліліт: 5°.
Хірон (3°), ASC і MC (5°) залишені без змін.
Значення використовуються в нових розрахунках без переданих pointOrbs,
у вбудованих профілях ревізії 2 та під час скидання орбісів в інтерфейсі.
Збережені карти, прогнози й користувацькі профілі не мігруються автоматично.

Алгоритм допуску аспекту не змінено: допустимий орбіс дорівнює мінімуму
ліміту типу аспекту й орбісів обох точок. Ліміти типів залишаються 8° для
з'єднання/опозиції, 7° для трина/квадрата та 5° для секстиля. Отже значення
планети 8,5° чи 9° саме по собі не розширює ці ліміти. Для прогресій та
сонячних дуг збережено окремий допуск 1°.

## Причина скидання

Раніше «Застосувати» робило лише preview-розрахунок у браузері та очищало
savedProfileId. У URL залишався chartId попередньої карти, тому після рефрешу
з бази завантажувався старий розрахунок зі старими орбісами.

## Поточна поведінка

Для власної збереженої карти «Застосувати» у налаштуваннях орбісів або профілю
розрахунку викликає `PUT /birth-profiles/:id/calculation`. API перевіряє
авторизацію та власника, бере дані народження із збереженої карти й обчислює
новий результат із переданими налаштуваннями. Орбіси допускають значення
від 0 до 15 градусів включно, з дробовою частиною.

Новий ChartCalculation додається до тієї самої карти: ID, видимість і посилання
не змінюються. Зберігаються settingsJson, resultJson, inputHash і версія рушія.
Існуючий механізм відкриття карти читає останній розрахунок за calculatedAt.
Попередні розрахунки, збережені прогнози й консультації не перезаписуються.
Астрологічні формули й спосіб застосування орбісів не змінені.

При помилці розрахунку або збереження UI показує помилку та не замінює
поточну карту новим результатом. Збереження не позначається успішним до
отримання відповіді API. Нова незбережена карта все ще потребує окремого
«Зберегти карту». Чужа карта за посиланням не змінюється: локальні налаштування
можна застосувати як preview, а результат зберегти окремою власною картою.
Застосування орбісів не змінює глобальний профіль за замовчуванням для нових карт.

## Перевірка після оновлення сервера

1. Відкрити власну збережену карту, змінити орбіси, натиснути «Застосувати».
2. Переконатися, що chartId не змінився; оновити сторінку і перевірити значення.
3. Відкрити цю ж карту зі списку: налаштування мають залишитися.
4. Скинути орбіси до базових, застосувати й повторити відкриття.
5. Перевірити, що користувач, який не є власником, не може змінити оригінал.

Додано `apps/api/tests/birth-profile-settings.test.ts`: авторизація, межі орбісів,
права власника, збереження snapshot, незмінність даних народження та обробка помилок.
Тести й збірка не запускалися на прохання користувача.
Для VPS потрібно оновити образи API та web; лише git pull недостатньо.
Міграція схеми бази даних для цієї зміни не потрібна.
